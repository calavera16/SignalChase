# Architecture

SignalTrace serves a static browser interface from a local FastAPI application. It uses NumPy/SciPy for numerical processing and a fixed Meta Responses transport for explicitly authorized investigations. There is no remote frontend build or raw-recording upload service.

## Modules

| Location | Responsibility |
| --- | --- |
| `signaltrace/recordings.py` | Bounded CSV parsing, explicit mappings, preserved timestamps, synthetic demos and optional manually installed data |
| `signaltrace/core.py`, `analysis.py`, `regional.py` | Deterministic filtering, support exclusions, candidate matching, measurements and descriptive regional evidence |
| `signaltrace/requirements.py` | Validated optional measurement limits and deterministic assessments |
| `signaltrace/investigation.py`, `investigation_jobs.py` | Bounded tool orchestration, evidence bindings, consented jobs and immutable job inputs |
| `signaltrace/explanation.py`, `explanation_jobs.py` | Separately consented, validated explanation scenes grounded in retained evidence |
| `signaltrace/meta_provider.py`, `credentials.py` | Fixed provider endpoint, bounded transport, public error categories and process-memory credentials |
| `signaltrace/research.py`, `replay.py`, `local_store.py` | Experiment metadata, numerical replay and bounded local persistence |
| `signaltrace/server.py`, `signaltrace/web/` | Loopback API, request guards, local waveform rendering, reports and findings animation |
| `signaltrace/experiment.py`, `__main__.py` | Offline synthetic experiment and locally generated reports |
| `scripts/build_public_repo.py`, `audit_public_repo.py` | Explicit source selection, fresh-folder export, manifest and redacted publication checks |

## Trust boundaries

The browser and server run for one trusted local user. A recording enters through a validated CSV body or a synthetic generator. Numerical tools own measurements. Meta can choose from allowed tools and provide interpretation; schemas, budgets and evidence validation constrain model output. No generated code is executed. A key connection is separate from consent to send research context.

The browser sends an API key only to the local credential endpoint. The server stores it in process memory and returns configuration status. The transport attaches authentication only to the fixed Meta endpoint. Disconnect clears future browser use and suppresses environment fallback; an in-flight job may retain its existing credential snapshot. This is not a public multi-user server design.

## Reproduction and scope

Synthetic inputs provide deterministic controls. Tests exercise numerical behavior, request validation, mocked transport, credentials, consent, export/replay and frontend rendering. Reports generated by those tests are temporary and never publication inputs. Optional downloaded-data tests skip without a local manual download. Historical real-recording evaluation protocols, live exports and film assets are deliberately outside the public source selection.

PPG preprocessing sensitivity is the implemented analysis module. Other modalities have generic recording inspection only. Candidate timing and count comparisons describe algorithmic setting dependence and do not establish a preferred physiological answer.
